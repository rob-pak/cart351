WEEK 1

Sept 14th

Last week, I read a blog post from Tim Rodenbröker, an educator in the creative coding sphere, titled "Is Creative Coding with AI… still Creative Coding?". This is a topic that immediately piqued my interest as I've always wondered where creative coding fits in a world of AI.

He posted a simple statement online which generated a lot of debate: "Creative Coding with AI is not Creative Coding". His issue seems to come from semantics, as the term "creative coding" seems, more often than not, to be used to describe the process of vibe-coding to create art, thus changing its meaning from what it was before AI. In his view, creative coding should still be done by hand, as that process comes with intention and discovery.

I wanted to highlight a few opinions shared by the community that I found interesting (paraphrased by me):

  • Coding "by hand" doesn't make it creative coding. There is a lot of derivative material that is just copy/paste with little expression. Tools that reduce the barrier to express yourself are of help.
  • "Manual coding" leads to accidental discoveries. The process is never a linear "idea to execution" pipeline that AI prompting seems to encourage. However, for boilerplate and repetitive code, there isn't anything wrong with AI. There's no creative potential in the thousandth time you write code to preload images.
  • Photography freed painting to go abstract, since realistic depiction was no longer painting's job.
  • Creative Prompting (as a suggestion for the term we should use to describe vibe-coding art)
  • Pottery analogy: the vase is not the end goal, but creating it through pottery is. Being able to vibe-code to reach a similar result to creative coding is giving the illusion of entering the same category, forgetting the value and meaning of the process itself.

Personally, AI is a depressing and difficult reality for me to accept. I still write my code manually and I still spend hours scratching my head. I think the struggle is an important part of learning and we should not outsource our thinking if we wish to prevail as a society. But part of me still sees a lot of value in AI in a learning environment when it is used correctly. I feel like a hypocrite!
